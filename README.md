# MCTB BAT — Site vitrine

Site statique frontend pour une entreprise générale de bâtiment.

## Lancer le site

Ouvrez simplement `index.html` dans un navigateur ou servez le dossier avec un serveur statique :

```bash
python3 -m http.server 8000
```

Puis consultez `http://localhost:8000`.

## Structure

- Pages HTML : accueil, à propos, métiers, réalisations, détail projet, engagements, actualités, contact et mentions légales.
- `assets/css/style.css` : design responsive et composants.
- `assets/js/app.js` : navigation mobile, animations d'apparition, filtres des réalisations et confirmation visuelle du formulaire.

Les photographies sont chargées depuis Unsplash à titre de démonstration.
